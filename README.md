# Silo Games

Web3 gaming studio site. Fun, economically sustainable games. Proof of Skill — earn by being good. PvP. May the best man win.

First title: **Strike Force**. Live.

## Stack

React 19, TanStack Start, Tailwind v4, Vite.

## Scripts

```bash
npm install
npm run dev
npm run build
```

The app listens on `0.0.0.0:8080` in this workspace.
